# LIVE MIX · Descargas

Instalador oficial de **LIVE MIX**, la app de SD Live Agency que convierte tu LIVE en un show: gráficos en vivo, voz que lee el chat, bot, juegos y minijuegos para TikTok LIVE Studio, Twitch y Kick.

**Descargar para Windows:** entra a [la última versión](../../releases/latest) y baja `LIVE-MIX-Setup.exe`.

Más información: https://sdliveagency.com/sd-mix-overlays-tiktok-live/
